# 拖拽合成与冷却表现

## 当前行为

- 合成业务结算后立即显示、排序结果；不再保留旧卡 0.22 秒，不再等待动画结束才接受下一次拖拽。成功/失败碎光只播放 0.25 秒，不改动实际卡槽的位置或缩放。
- 合成区固定自动排列：阶数降序、等级降序、配置的法术显示优先级升序、实例 ID 升序；不保存格位，不支持交换位置或自定义布局。
- 成功事件携带创建时的 ResultInstanceId。反馈使用这个 ID 定位，避免在自动排序、待领取法术补入后猜错产物。
- 四种法术图标按配置的 iconResourceKey 直接引用在 MainWindow prefab 中。刷新/拖动/合成不再调用异步图标加载，图标在 Render 返回时已与数据一致。配置新增类型时需运行编辑器的 Update Spell Presentation Prefab 菜单补齐引用。
- 当前合成配置依然是随机选择四种法术之一，成功产物并不保证与输入法术同类型。
- 一阶古铜细框、二阶青铜绿粗框、三阶紫墨粗框加金色内线，沿用原纸牌切角轮廓；去掉旧圆环、菱形与放射纹章。主图保持法术类型一致，阶数用边框与文字识别。
- 冷却继续使用 tile_spellSlotBase 的原生 Radial360 Image 覆盖完整卡槽；TMP 数字居中。
- CanvasGroup、阶数框、碎光、遮罩以及图标引用均保存到 prefab；运行时只更新显示状态，无临时 GameObject/AddComponent 或按名称查找。

## 验证与边界

隔离 Unity 项目编译、EditMode 回归及 UI 渲染。新增覆盖：阶数/等级排序、真实产物 ID、连续切换四类图标、合成状态中立即刷新结果。预览为构造的法术与冷却状态：outputs/spell-presentation/SpellPresentation.png。

已移除确定存在的人工等待和图标异步加载路径。未取得用户运行环境的 Profiler 帧记录，因此不将这两项改动等同于排除了所有 CPU/GPU 卡顿。同步业务调用可在 Profiler 查看 Inkspell.Synthesis.Commit。
