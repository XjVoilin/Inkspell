## 注册与初始化顺序约束

`HotUpdateRegistrar.Register()` 保持当前框架机制注册，并按实际依赖满足：`ConfigSystem/JsonSerializeSystem/NoEncryptionSystem/LocalFileSaveSystem/TimeSystem` → 全部 Store 注册及三个持久 Store 的 `Persist()` 声明 → `SpellAssetSystem` → 合成/养成 → `AutoBattleSystem` → `StageProgressionSystem` → `SpellGenerationSystem`。`PreInitializeAsync()` 仍先加载 Luban 和本地化，然后 `ArchContext.InitializeAsync()` 先恢复 Store 再初始化业务 System。

## 验收标准

- `HotUpdateRegistrar` 仅做注册、持久化声明和启动连接，不接管业务规则。
- 三个持久 Store 与一个非持久 Store 边界准确；所有 `Persist()` 均发生在 SaveSystem 初始化前。
- 普通 MDD 声明的七个延迟集成项全部落地，无额外业务入口、状态或页面。
- Luban 生成与 Unity C# 编译通过；不创建测试、Scene 或新的业务美术资源。本次仅按用户授权补齐 `UIInkspellMainWindow`、`UIOfflineRewardWindow` 两个 Prefab 与 TMP 必需基础资源。
