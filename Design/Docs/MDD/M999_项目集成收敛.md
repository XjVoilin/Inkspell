## 注册与初始化顺序约束

HotUpdateRegistrar.Register() 保持当前框架机制和既有三个持久业务 Store 的注册/Persist 声明，只移除 AutoBattleStore，并满足：Framework 机制 → SpellAssetStore、StageProgressionStore、SpellGenerationStore → SpellAssetSystem → SpellSynthesisSystem、SpellProgressionSystem → AutoBattleSystem → StageProgressionSystem → SpellGenerationSystem → OfflineRewardPresentationSystem。

PreInitializeAsync() 继续使用当前 Luban 动态表清单完成配置与本地化加载；ArchContext.InitializeAsync() 先由 LocalFileSaveSystem 恢复三个持久 Store，再按注册顺序初始化业务 System。
