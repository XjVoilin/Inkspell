# M011 法术区拖拽与装备交互

文档类型：MDD

- 来源模块设计：`../模块设计.md`
- 来源 GDD：`../GDD.md`

## 目标与边界

为主界面增加 6×4 合成区、四装备槽、稳定排列显示及点击/拖拽意图产出。GameView 只维护拖拽影子、命中和选中等表现状态；合法性、合成结算与装备原子交换由业务 System 完成。

## 对应模块设计

- 所属范围：法术资产与法术合成的跨模块 View 切片，不新增业务模块。
- 容量、排序、锁定、位置和事务编排仍分别由资产/合成模块拥有。

## 对应 GDD 内容

对应 §7.3—4、§9、§10、§12.1、§15.1—3、§18 拖拽与合成边界、§20.3—6。

## 实施范围

### 创建

- `Assets/Game/Scripts/Runtime/Views/SpellBoardViewData.cs`：合成区与装备槽显示数据。
- `Assets/Game/Scripts/Runtime/Views/UISpellBoardGameView.cs`：合成格复用、稳定渲染与拖拽命中。
- `Assets/Game/Scripts/Runtime/Views/UIEquipmentBarGameView.cs`：四槽显示与投放命中。
- `Assets/Game/Scripts/Runtime/Views/UISpellCardGameView.cs`：单卡显示、点击和 Unity EventSystems 拖拽事件。

### 修改

- `Assets/Game/Scripts/Runtime/Views/UIInkspellMainWindowData.cs`：增加 `SpellBoard`、`EquipmentBar` 和对应局部刷新。
- `Assets/Game/Scripts/Runtime/Views/UIInkspellMainWindow.cs`：绑定两个子 GameView，将二合、装备意图交给资产/合成 System，并消费结果事件刷新/显示 Tip；法术点击只由合成区 GameView 产出，主 Window 对该事件的详情导航由 M013 增量接入。
- `Tools/Luban/DataTables/Datas/Language.xlsx`：新增不同阶、锁定、已装备、最高阶、已培养等失败 Tip 与合成结果文本。

### 不涉及

- 不创建拖拽 Prefab、格子布局或 Inspector 绑定；不持久化显示格索引。
- 不在 View 复算合成合法性、排序规则或装备替换步骤。

## 状态与数据

`SpellCardViewData` 包含实例 ID、法术种类、阶级、等级、锁定、图标资源键与阶级显示键；图标资源键来自配置/WindowData，不是图片本身。GameView 仅保存当前拖拽实例 ID、影子位置和命中目标。

## View 代码

- 重复卡片/槽位 GameView 不实现 `ISingletonView`。
- 可复用 `UIItemSlot` 的空/满、图标、选中显示；拖拽通过 `IBeginDragHandler`、`IDragHandler`、`IEndDragHandler`、`IDropHandler` 增补，不改写 `UIItemSlot`。
- 拖到空格或无合法目标只恢复表现位置，不调用业务 System。
- 拒绝事实由 Window 使用 `ILocalizationSystem.Get(key)` 与 `IUISystem.ShowTip()` 显示；Window 不重复推断原因。

## 验收标准

- 合成区显示顺序完全来自资产查询；换装、合成、生成、升级、锁定后可即时刷新。
- View 只提交意图；非法合成不消耗状态并显示业务模块给出的具体原因。
- 使用现有 July UI 组件/API，不运行时自动挂组件或查找以弥补 Prefab。
- 编译通过，不创建测试、Prefab、图片或 Scene。
