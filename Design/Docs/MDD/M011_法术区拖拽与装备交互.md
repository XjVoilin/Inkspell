# M011 法术区拖拽与装备交互

文档类型：MDD

- 来源模块设计：../模块设计.md
- 来源 GDD：../GDD.md

## 目标与边界

复用现有法术卡、合成区和装备槽 GameView，把玩家装备意图直接交给 SpellAssetStore，把二合意图交给同步 SpellSynthesisSystem。GameView 只维护拖拽影子、选中和命中等表现状态；不复算排序、合法性或原子替换步骤。

## 对应模块设计

- 所属范围：法术资产/法术合成的 UI 表现集成，不新增业务模块。
- 单 Store 同步装备由 Window 直接调用 Store 语义方法。
- 二合仍由法术合成 System 唯一编排；非法落点只恢复表现。

## 对应 GDD 内容

对应 §7.3—4、§9、§10、§12.1、§15.1—3、§18 与 §20.3—6。

## 实施范围

### 创建

无。

### 修改

- Assets/Game/Scripts/Runtime/Views/UIInkspellMainWindow.cs：将 SpellAssetSystem 字段替换为 SpellAssetStore；OnEquipRequested() 调用 TryEquip()；OnSynthesisRequested() 调用同步 TrySynthesize()。
- Assets/Game/Scripts/Runtime/Views/UISpellBoardGameView.cs、UIEquipmentBarGameView.cs、UISpellCardGameView.cs：复用现有渲染与 EventSystems 拖拽入口，仅按目标 Data/API 做必要对齐。
- Assets/Game/Scripts/Runtime/Views/SpellBoardViewData.cs：继续作为显示输入，不引用 SpellInstance 或 Store Data。

### 复用

- 现有 UIItemSlot、IBeginDragHandler、IDragHandler、IEndDragHandler、IDropHandler。
- 现有 Language.xlsx 合成拒绝/结果文本与 IUISystem.ShowTip()。

### 不涉及

- 不创建或修改 Prefab、格子布局、拖拽资源或 Inspector 绑定。
- 不在 View 判断合成六项条件、装备容量或资产提交顺序。

## 前置依赖

- M002：需要 SpellAssetStore.TryEquip()。
- M004：需要同步 SpellSynthesisSystem.TrySynthesize() 及现有结果事实。

## 延迟集成

无。调用点迁移在本 MDD 内完成；Prefab/Inspector 不属于 M999。

## 角色与职责

| 类型 | 所属范围 | JulyArch 角色 | 职责 | 必要协作 |
|---|---|---|---|---|
| UISpellBoardGameView | UI 表现集成 | GameView | 渲染合成格并报告点击/二合意图 | SpellBoardViewData |
| UIEquipmentBarGameView | UI 表现集成 | GameView | 渲染装备槽并报告投放意图 | EquipmentBarViewData |
| UISpellCardGameView | UI 表现集成 | GameView | 单卡显示与指针交互 | Unity EventSystems |
| SpellBoardViewData | UI 表现集成 | ViewData | 合成区唯一显示输入 | 主 WindowData |

## 状态与数据

SpellCardViewData 继续保存纯显示字段；GameView 只保存当前拖拽、影子位置、命中与选中状态。业务实例仍由 SpellAssetStore 唯一拥有。

## 行为与公开能力

| 类型 | 准确公开签名 | 语义 | 返回与失败处理 |
|---|---|---|---|
| UISpellBoardGameView | public void Render(SpellBoardViewData data) | 按 Data 渲染固定格 | 不查询业务 |
| UISpellBoardGameView | public event Action<long> SpellClicked | 报告详情意图 | M013 导航 |
| UISpellBoardGameView | public event Action<long, long> SynthesisRequested | 报告二合意图 | Window 调用同步 System |
| UIEquipmentBarGameView | public event Action<long, int> EquipRequested | 报告装备意图 | Window 调用 Store |
| UISpellCardGameView | public void Render(SpellCardViewData data) | 单卡纯显示 | 不持有可写业务对象 |

## View 代码

拖到空格或无合法目标只恢复表现，不调用业务。合成拒绝/结果仍由 Window 消费业务事实并映射本地化 Tip；Window 不重复判断原因。

## 验收标准

- Window 不再通过 SpellAssetSystem 装备，也不调用异步合成入口。
- 合成区排序只来自 WindowData；View 不写 Store Data。
- 现有 UI 组件/API 复用且不运行时自动挂载或查找。
- 编译通过；不创建测试、Prefab、Scene、图片或其他资源。
