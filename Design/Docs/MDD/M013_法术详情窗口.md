# M013 法术详情窗口

文档类型：MDD

- 来源模块设计：../模块设计.md
- 来源 GDD：../GDD.md

## 目标与边界

调整现有法术详情 Window/WindowData，使详情数据和锁定意图直接使用 SpellAssetStore，升级信息与升级意图继续交给 SpellProgressionSystem。窗口只显示单实例种类、阶级、等级、主数值、位置、锁定和升级信息，不解释成本、上限或战斗生效时机。

## 对应模块设计

- 所属范围：法术资产/法术养成的 UI 表现集成，不新增业务模块。
- WindowData 从 Store/System 组装；Window 对单 Store 锁定直接调用 Store 语义方法。
- 业务失败由责任方法与事件表达，View 不重复判定。

## 对应 GDD 内容

对应 §7、§9.2、§11.2、§12.1、§15.2—3、§18 与 §20.5、7。

## 实施范围

### 创建

无。

### 修改

- Assets/Game/Scripts/Runtime/Views/UISpellDetailWindowData.cs：把 SpellAssetSystem 查询与墨水读取替换为 SpellAssetStore；直接读取实时 SpellInstanceState 并转换为 WindowData 字段。
- Assets/Game/Scripts/Runtime/Views/UISpellDetailWindow.cs：把锁定调用替换为 SpellAssetStore.TrySetLocked()；升级继续调用 SpellProgressionSystem.TryUpgrade()。
- Assets/Game/Scripts/Runtime/Views/UIInkspellMainWindow.cs：复用现有 SpellClicked 导航和 Data 注入。

### 复用

- Assets/Game/Scripts/Runtime/Views/UIWindowID.cs 的 UISpellDetailWindow = 13。
- Tools/Luban/DataTables/Datas/UIWindow.xlsx 中同名 ID 13 记录。
- 现有 UIToggleButton、UISmartButtonGray、UICloseButton、本地化文本与升级事实。

### 不涉及

- 不创建详情 Prefab、图标、动画或 Inspector 绑定。
- 不在 WindowData 修改 Store、执行升级、导航或运行 Procedure。

## 前置依赖

- M002：需要 SpellAssetStore.TryGetSpell()、MagicInk 与 TrySetLocked()。

## 延迟集成

无。导航与调用点在现有主窗口/详情窗口中直接完成。

## 角色与职责

| 类型 | 所属范围 | JulyArch 角色 | 职责 | 必要协作 |
|---|---|---|---|---|
| UISpellDetailWindow | UI 表现集成 | Window | 详情生命周期、渲染和锁定/升级意图提交 | SpellAssetStore、SpellProgressionSystem |
| UISpellDetailWindowData | UI 表现集成 | WindowData | 组装指定实例、配置与升级信息 | Store/System/IConfigSystem |

## 状态与数据

WindowData 保持现有 GM 可写显示字段；正常构造时读取实时资产实例并复制为显示值，不保存 Store Data 引用。Window 只保存注入 Data、按钮状态与当前反馈表现。

## 行为与公开能力

| 类型 | 准确公开签名 | 语义 | 返回与失败处理 |
|---|---|---|---|
| UIWindowID | public const int UISpellDetailWindow = 13 | 详情窗口 ID | 与 TbUIWindow 同名同值 |
| UISpellDetailWindowData | public UISpellDetailWindowData() | 未注入/GM 默认显示输入 | 不查询或修改业务 |
| UISpellDetailWindowData | public UISpellDetailWindowData(long spellInstanceId) | 正常查询指定实例 | 调用方只传存在实例 |
| UISpellDetailWindowData | public void Refresh() | 刷新资产、配置和升级显示 | 不执行业务动作 |

## View 代码

OnBeforeOpen() 使用注入 Data，否则创建默认 Data。锁定直接调用 Store；升级调用养成 System；成功或拒绝后刷新 Data 并使用 IUISystem.ShowTip()。

## 验收标准

- WindowData/Window 不再依赖 SpellSnapshot 或 SpellAssetSystem 的转发。
- Window、UIWindowID 与 TbUIWindow 保持 UISpellDetailWindow/13。
- 锁定不影响升级/装备；墨水不足和满级不修改资产。
- 编译通过；不创建测试、Prefab、Scene 或美术资源。
