# M013 法术详情窗口

文档类型：MDD

- 来源模块设计：`../模块设计.md`
- 来源 GDD：`../GDD.md`

## 目标与边界

建立法术详情 Window 与 WindowData，显示单个实例的种类、阶级、等级、主要数值、锁定和升级信息，并把锁定/升级意图交给对应 System。它不解释成本、上限、合成限制或战斗生效时机。

## 对应模块设计

- 所属范围：法术资产与法术养成的跨模块 View 切片，不新增业务模块。
- WindowData 从资产/养成稳定能力组装；业务失败由事件驱动反馈。

## 对应 GDD 内容

对应 §7、§9.2、§11.2、§12.1、§15.2—3、§18 墨水/满级边界及 §20.5、7。

## 实施范围

### 创建

- `Assets/Game/Scripts/Runtime/Views/UISpellDetailWindow.cs`：继承 `UIView`。
- `Assets/Game/Scripts/Runtime/Views/UISpellDetailWindowData.cs`：单实例详情唯一显示输入。

### 不涉及

- 不创建详情 Prefab、图标、动画或 Inspector 绑定；不提供培养返还/重置/降级。

## 延迟集成

无。页面导航在本 MDD 对主 Window 的增量修改中完成。

## 角色与职责

| 类型 | 所属模块 | JulyArch 角色 | 职责 | 必要协作 |
|---|---|---|---|---|
| `UISpellDetailWindow` | 跨模块 View | Window | 详情生命周期、渲染和玩家意图提交 | 资产/养成 System |
| `UISpellDetailWindowData` | 跨模块 View | WindowData | 组装指定实例与升级信息 | `SpellAssetSystem`、`SpellProgressionSystem` |

## 状态与数据

WindowData 包含实例 ID、显示名键、阶级/等级、当前位置、锁定、当前墨水、成本、满级状态与升级前后主要倍率。Window 的按钮按压与当前播放反馈属于表现状态。

## 行为与公开能力

| 类型 | 准确公开签名 | 语义 | 返回与失败处理 |
|---|---|---|---|
| `UIWindowID` | `public const int UISpellDetailWindow = 13` | 详情窗口 ID | 与 Luban 同名同值 |
| `UISpellDetailWindowData` | `public UISpellDetailWindowData()` | 未注入/GM 的默认空显示 Data | Window 始终只渲染 Data |
| `UISpellDetailWindowData` | `public UISpellDetailWindowData(long spellInstanceId)` | 正常查询指定实例 | 调用方只传存在实例 |
| `UISpellDetailWindowData` | `public void Refresh()` | 刷新资产与升级信息 | 不执行业务动作 |

## View 代码

- `OnBeforeOpen()` 使用注入 Data，否则创建默认 Data。
- 锁定使用 `UIToggleButton` 或现有 `UISmartButton`；升级使用 `UISmartButtonGray.SetInteractable()`，关闭优先使用 `UICloseButton`。
- 点击后 Window 调用 `TrySetLocked()`/`TryUpgrade()`；成功或拒绝事件到达后刷新 Data，并使用本地化文本和 `IUISystem.ShowTip()` 反馈。

## 验收标准

- Window、ID 常量、TbUIWindow 三者严格一致；页面有 WindowData 与默认构造。
- 锁定不影响升级/装备；墨水不足和满级不修改资产且反馈明确。
- Window 不读 Store、不复算成本/上限、不运行 Procedure。
- 编译通过，不创建测试、Prefab、Scene 或美术资源。
