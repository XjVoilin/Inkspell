# M003 法术资产业务入口

文档类型：MDD

- 来源模块设计：`../模块设计.md`
- 来源 GDD：`../GDD.md`

## 目标与边界

创建法术资产模块唯一 System，为 View 与授权业务模块提供只读查询、锁定、装备、生成接收以及合成/升级原子提交入口。System 不拥有合成随机、升级成本或生成规则。

## 对应模块设计

- 所属模块：法术资产；落实唯一 System 规划。
- 保持“资产只对自身单 Store 原子提交，事务规则由合成/养成/生成解释”的协作边界。

## 对应 GDD 内容

对应 §7.1、§7.4、§9、§11.1、§12、§14.1、§18 和 §20.2。

## 实施范围

### 创建

- `Assets/Game/Scripts/Runtime/Modules/SpellAssets/SpellAssetSystem.cs`：资产长期稳定入口。

### 修改

无。

### 不涉及

- 不创建 `ISpellAssetSystem`、Result 包装、Snapshot、静态管理器或项目配置聚合器。
- 不调用 UI Tip；业务失败日志和事实由责任方法产生，View 只刷新或显示对应反馈。

## 前置依赖

- M001：需要领域只读类型与 Luban 表。
- M002：需要唯一资产 Store 及其语义修改。

## 延迟集成

- M999:I001：在 `HotUpdateRegistrar.Register()` 中于 Store 和框架依赖之后注册 `SpellAssetSystem`。

## 角色与职责

| 类型 | 所属模块 | JulyArch 角色 | 职责 | 必要协作 |
|---|---|---|---|---|
| `SpellAssetSystem` | 法术资产 | System | 查询资产并向 Store 提交资产模块拥有的语义修改 | `SpellAssetStore`、`IConfigSystem` |

## 状态与数据

System 无独立状态。初始化时读取 `TbSpellAssetRule`；若持久 Store 未初始化则建立 GDD 初始进度。所有查询转换为 `SpellInfo`，未装备列表按 `TbSpellDefinition.DisplayPriority` 后按 `InstanceId` 排序。

## 行为与公开能力

| 类型 | 准确公开签名 | 语义 | 返回与失败处理 |
|---|---|---|---|
| `SpellAssetSystem` | `public int MagicInk { get; }` | 当前墨水 | 只读 |
| `SpellAssetSystem` | `public int CraftingCapacity { get; }` | 配置容量 | 只读 |
| `SpellAssetSystem` | `public int RemainingCraftingCapacity { get; }` | 当前剩余容量 | 只读派生值 |
| `SpellAssetSystem` | `public IReadOnlyList<SpellInfo> GetCraftingAreaSpells()` | 稳定排列的未装备法术 | 返回新只读列表，不暴露 Store 集合 |
| `SpellAssetSystem` | `public SpellInfo? GetSpell(long instanceId)` | 查询指定实例 | 不存在返回 `null` |
| `SpellAssetSystem` | `public SpellInfo? GetEquippedSpell(int equipmentSlot)` | 查询槽位 | 空槽返回 `null`；非法槽位为调用契约错误 |
| `SpellAssetSystem` | `public bool TrySetLocked(long instanceId, bool locked)` | 设置锁定 | 实例不存在记录日志并返回 `false` |
| `SpellAssetSystem` | `public bool TryEquip(long instanceId, int equipmentSlot)` | 从合成区装备或替换 | 普通无效操作记录上下文并返回 `false` |
| `SpellAssetSystem` | `public bool TryReceiveGeneratedSpell(SpellType type)` | 有容量时创建一阶 1 级实例 | 满格返回 `false`，不修改状态 |
| `SpellAssetSystem` | `public bool TryCommitSynthesisSuccess(long firstId, long secondId, SpellType resultType, int resultTier)` | 原子消耗并创建产物 | 提交失败返回 `false`，不暴露半成品 |
| `SpellAssetSystem` | `public bool TryCommitSynthesisFailure(long firstId, long secondId, int inkReward)` | 原子消耗并发墨水 | 提交失败返回 `false` |
| `SpellAssetSystem` | `public bool TryCommitUpgrade(long instanceId, int inkCost)` | 原子扣墨水并升一级 | 余额不足或实例不存在返回 `false` |

## 验收标准

- System 公开能力均服务资产长期能力，且只存在一个具体 System。
- 读取不暴露 Store Data；排序、容量和装备映射与 GDD 一致。
- 合成、养成、生成调用方不需要知道 Store 修改步骤。
- 项目可编译，无接口配套、Result、Snapshot、测试或运行时巡检。
