# M002 法术资产权威状态

文档类型：MDD

- 来源模块设计：../模块设计.md
- 来源 GDD：../GDD.md

## 目标与边界

深化现有 SpellAssetStore，使它直接承担资产读取、锁定、装备、生成接收、合成结算和升级提交等单 Store 语义，并继续唯一持久化法术实例、位置、装备、锁定、ID 与魔法墨水。它不解释合成概率、升级成本、生成计时或显示排序。

## 对应模块设计

- 所属模块：法术资产；落实唯一持久 Store。
- Store 可脱离 SpellAssetSystem 被合成、养成、生成、自动战斗和 WindowData 独立读取或调用。
- 外部按只读约定使用 SpellAssetStoreData/SpellInstanceState，不直接修改字段或集合；所有变化只经 Store 语义方法完成。
- 修改完整提交后再 MarkDirty() 和发布 SpellAssetsChangedEvent。

## 对应 GDD 内容

对应 §7、§9、§10.2、§11、§12、§14.1、§14.3 第 5 条、§18 与 §20.2—7。

## 角色与职责

| 类型 | 所属模块 | JulyArch 角色 | 职责 | 必要协作 |
|---|---|---|---|---|
| SpellAssetStoreData | 法术资产 | Store Data | 持久化初始化标记、下一 ID、墨水与实例集合 | LocalFileSaveSystem |
| SpellInstanceState | 法术资产 | Store Data 项 | 表达一张实时法术实例；跨模块只读 | Store 语义方法 |
| SpellAssetStore | 法术资产 | Store | 维护资产不变量、派生索引和单 Store 原子修改 | M003—M013 |

## 状态与数据

- SpellAssetStoreData 继续包含 Initialized、NextInstanceId、MagicInk、Spells。
- SpellInstanceState 继续包含 InstanceId、Type、Tier、Level、Location、EquipmentSlot、IsLocked。
- Spells、GetData() 与查询返回值都是实时权威数据引用；调用方只读，不能保存为第二份可写真相。
- 合成区计数、装备槽映射和 ID 索引是 Store 内部派生状态；ReplaceData() 后只重建这些索引。
- 容量与槽位边界由 M003 在恢复后通过 Initialize(TbSpellAssetRule) 建立；合法空合成区不等于新档。

## 行为与公开能力

以下 internal 签名是同一 Game.Runtime 程序集内的稳定模块契约：

| 类型 | 准确签名 | 语义 | 返回与失败处理 |
|---|---|---|---|
| SpellAssetStore | internal int MagicInk { get; } | 当前墨水 | 只读 |
| SpellAssetStore | internal int RemainingCraftingCapacity { get; } | 当前剩余容量 | 只读派生值 |
| SpellAssetStore | internal IReadOnlyList<SpellInstanceState> GetCraftingAreaSpellStates() | 未装备实例实时引用 | 不排序，不暴露可写集合 |
| SpellAssetStore | internal bool TryGetSpell(long instanceId, out SpellInstanceState spell) | 查询指定实例 | 不存在返回 false |
| SpellAssetStore | internal bool TryGetEquippedSpell(int equipmentSlot, out SpellInstanceState spell) | 查询槽位实例 | 空槽返回 false |
| SpellAssetStore | internal bool TrySetLocked(long instanceId, bool locked) | 切换锁定 | 不存在记录上下文并返回 false |
| SpellAssetStore | internal bool TryEquip(long instanceId, int equipmentSlot) | 装备或原子替换 | 普通无效操作记录并返回 false |
| SpellAssetStore | internal bool TryReceiveGeneratedSpell(SpellType type) | 有容量时接收一阶 1 级产物 | 满格返回 false |
| SpellAssetStore | internal void CommitSynthesisSuccess(long firstId, long secondId, SpellType resultType, int resultTier) | 消耗输入并创建成功产物 | 只接受合成 System 已建立的契约；违约快速失败 |
| SpellAssetStore | internal void CommitSynthesisFailure(long firstId, long secondId, int inkReward) | 消耗输入并增加墨水 | 负奖励或预检后违约快速失败 |
| SpellAssetStore | internal void CommitUpgrade(long instanceId, int inkCost) | 在养成 System 完成普通失败判定后原子扣墨水并升一级 | 不重复检查实例、满级或余额；契约违约自然失败或快速失败 |
| SpellAssetStore | internal void Initialize(TbSpellAssetRule rule) | 恢复后建立容量边界并在新档补初始资产 | 仅 Initialized=false 时写入新档 |
| SpellAssetsChangedEvent | public SpellAssetsChangedEvent(bool capacityIncreased) | 构造资产完整提交后的变化事实 | 只由 Store 在提交后发布 |
| SpellAssetsChangedEvent | public bool CapacityIncreased { get; } | 本次提交是否增加合成区容量 | 生成模块据此尝试补入 |

## 验收标准

- 其他模块不再必须经过 SpellAssetSystem 才能读取或修改 Store 拥有的同步语义。
- 一个 Store 原子维护实例与墨水；装备、合成和升级不暴露中间态。
- Store Data 不包含显示格索引、战斗状态或 Luban 静态配置。
- 无第二 Store、Snapshot 新类型、全量复检、测试或兜底实现。
