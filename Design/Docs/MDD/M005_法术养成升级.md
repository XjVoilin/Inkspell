# M005 法术养成升级

文档类型：MDD

- 来源模块设计：../模块设计.md
- 来源 GDD：../GDD.md

## 目标与边界

保留现有 SpellProgressionSystem 作为升级规则和事务的唯一长期入口，改为直接读取并调用 SpellAssetStore。模块继续无 Store、无 Procedure，不拥有墨水或等级，也不处理返还、重置、降级和战斗执行。

## 对应模块设计

- 所属模块：法术养成。
- System 集中解释成本、上限、成长、墨水不足和成功提交。
- 法术实例、等级与墨水仍唯一属于法术资产 Store。

## 对应 GDD 内容

对应 §7.1、§10.4、§11、§14.3 第 4 条、§17.1、§18、§19.1 第 12 项及 §20.7。

## 实施范围

### 创建

无。

### 修改

- Assets/Game/Scripts/Runtime/Modules/SpellProgression/SpellProgressionSystem.cs：把 SpellAssetSystem 依赖替换为 SpellAssetStore；GetUpgradeInfo() 直接读取实例和墨水；TryUpgrade() 唯一判定实例、满级和墨水不足，随后调用 Store.CommitUpgrade() 原子提交，不再处理第二次同类失败。
- Assets/Game/Scripts/Runtime/Modules/SpellProgression/SpellUpgradeTypes.cs：复用现有真实升级计算产物与事件，不创建 Result。

- 现有满级、墨水不足及预检后提交违约快速失败行为。

### 不涉及

- 不修改配置数值、生成产物、战斗状态或 UI 组件。

## 状态与数据

无长期状态。SpellUpgradeInfo 是当次规则计算产物，不是成功失败包装或领域快照。System 只在调用栈内读取 SpellInstance；成功修改由 SpellAssetStore 原子完成。

## Luban 配置

复用现有作者源和生成 API；满级由配置 IsMaxLevel 明确表达，不以缺行推断，不在 C# 复制曲线与成本。

## 验收标准

- 实例、墨水不足和满级只由养成 System 判定；普通失败不修改状态，成功由 Store 一次提交墨水与指定实例等级。
- System 不再依赖 SpellAssetSystem 的查询或提交转发。
- Store 提交不重复返回 System 已经排除的普通业务失败；无新增 Store、Procedure、Result、配置巡检或测试。
- Luban 生成类型与项目编译保持通过。
