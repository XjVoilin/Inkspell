# M010 主界面窗口与显示数据

文档类型：MDD

- 来源模块设计：../模块设计.md
- 来源 GDD：../GDD.md

## 目标与边界

调整现有 UIInkspellMainWindowData，使其按目标角色直接从 SpellAssetStore、SpellGenerationStore、StageProgressionStore、SpellAssetSystem 与 AutoBattleSystem.CurrentRun 组装主界面唯一显示输入。Window 只协调页面生命周期、事件刷新和子 GameView；不读取 Store Data 字段来修改业务、不运行 Procedure。

## 对应模块设计

- 所属范围：UI 表现集成，不新增业务模块。
- WindowData 负责首屏和局部刷新；Window/GameView 只根据 Data 渲染。
- 墨水、装备和容量从资产 Store 读取；待领取和生成周期从生成 Store 读取；当前关卡从关卡 Store 读取；未装备稳定排列仍由资产 System 解释。

## 对应 GDD 内容

对应 §3、§4、§15、§19.1 第 1 项与 §20.1、13—14。布局比例仍属于 Prefab/真机表现，不在本 MDD 修改。

## 实施范围

### 创建

无。

### 修改

- Assets/Game/Scripts/Runtime/Views/UIInkspellMainWindowData.cs：直接从三个持久 Store 读取资产、生成和关卡状态；使用 GetSortedCraftingAreaSpells() 组装合成区；从 AutoBattleSystem.CurrentRun 直接转换 BattlefieldViewData，不创建中间副本。
- Assets/Game/Scripts/Runtime/Views/UIInkspellMainWindow.cs：只做与目标 Data/API 对齐的页面级刷新；装备、合成动作的具体迁移由 M011 承担。
- Assets/Game/Scripts/Runtime/Views/MainStatusViewData.cs、SpellBoardViewData.cs、BattlefieldViewData.cs：复用现有 WindowData 子数据，不引入领域 Snapshot。

### 复用

- Assets/Game/Scripts/Runtime/Views/UIWindowID.cs 的 UIInkspellMainWindow = 12。
- Tools/Luban/DataTables/Datas/UIWindow.xlsx 中同名 ID 12 记录。
- 现有 UIProgressBar、UISmartButton、UILocalizedText 与主界面事件订阅。

### 不涉及

- 不修改 Prefab、Scene、Canvas、安全区、图片、动画或 Inspector。
- WindowData 不执行业务动作、导航、Store 写入或 Procedure。

## 角色与职责

| 类型 | 所属范围 | JulyArch 角色 | 职责 | 必要协作 |
|---|---|---|---|---|
| UIInkspellMainWindow | UI 表现集成 | Window | 页面生命周期、事件刷新与子区域协调 | WindowData、业务入口 |
| UIInkspellMainWindowData | UI 表现集成 | WindowData | 从目标 Store/System 组装唯一显示输入 | ArchContext |
| MainStatusViewData | UI 表现集成 | ViewData | 关卡、墨水、生成和魔法书概要 | WindowData |
| UIWindowID | UI 机制 | 纯常量 | 与 TbUIWindow 一一对应 | Luban |

## 状态与数据

Window 只保存注入 Data 与纯表现状态。WindowData 不复制可写权威集合；它把实时业务事实转换为可由 GM 构造/覆盖的 SpellCardViewData、BattlefieldViewData 等显示值。

## 行为与公开能力

| 类型 | 准确公开签名 | 语义 | 返回与失败处理 |
|---|---|---|---|
| UIWindowID | public const int UIInkspellMainWindow = 12 | 主窗口 ID | 与 TbUIWindow 同名同值 |
| UIInkspellMainWindowData | public UIInkspellMainWindowData() | 正常首屏查询构造及未注入默认 Data | 已注册依赖缺失自然失败 |
| UIInkspellMainWindowData | public void RefreshStatus() | 刷新常驻状态 | 只读查询 |
| UIInkspellMainWindowData | public void RefreshSpellBoard() | 刷新稳定排列合成区 | 不修改 Store |
| UIInkspellMainWindowData | public void RefreshEquipmentBar() | 刷新装备槽 | 不修改 Store |
| UIInkspellMainWindowData | public void RefreshBattlefield() | 刷新战场显示输入 | 不推进战斗 |
| UIInkspellMainWindowData | public void RefreshAll() | 聚合局部刷新 | 不执行业务动作 |

## View 代码

Window 类型、UIWindowID 字段和 TbUIWindow 记录均保持 UIInkspellMainWindow/12。OnBeforeOpen() 使用注入 Data，否则创建默认 Data；正常与 GM 显示都只渲染 Data。

## 验收标准

- WindowData 不再依赖 SpellSnapshot、BattleViewState 或资产 System 的转发查询。
- 主窗口、ID 和 TbUIWindow 仍同名同值，且未注入时创建默认 Data。
- Window/GameView 不绕过 Data 渲染，不修改业务状态或运行 Procedure。
- 编译通过；不创建测试、Prefab、Scene 或美术资源。
