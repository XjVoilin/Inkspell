# M001 法术资产配置与领域契约

文档类型：MDD

- 来源模块设计：../模块设计.md
- 来源 GDD：../GDD.md

## 目标与边界

确认并复用已经落地的法术定义、阶级、资产规则和位置契约，为后续 Store/System 迁移提供稳定配置事实。本 MDD 不创建玩家资产状态，不修改配置数值，不保留 SpellSnapshot 作为目标读取层。

## 对应模块设计

- 所属模块：法术资产。
- 对应法术身份、位置互斥、容量、稳定排列、新进度初始资产和配置派生事实。
- 配置继续由 IConfigSystem 读取；不建立项目 ConfigSystem、ContentSystem 或 C# 配置镜像。
- SpellSnapshot 是现有迁移事实，不是目标角色；待全部消费者迁移后由 M999:I008 删除。

## 对应 GDD 内容

对应 §4.1、§5、§7、§9、§12、§14.1、§17.1、§17.5 与 §20.2。具体首版数值仍唯一保存在现有 Luban 作者源中。
