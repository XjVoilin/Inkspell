# M001 法术资产配置与领域契约

文档类型：MDD

- 来源模块设计：`../模块设计.md`
- 来源 GDD：`../GDD.md`

## 目标与边界

建立法术资产模块实施所需的 Luban 静态事实和跨 MDD 稳定领域类型。负责法术种类、开放状态、显示优先级、阶级边界、装备槽/合成区规模与新进度初始资产配置；不创建玩家资产状态，不实现合成、升级、生成或战斗。

## 对应模块设计

- 所属模块：法术资产。
- 对应“独立法术实例、合成区容量与稳定排列、四装备槽、初始火球”的资产决策。
- 配置仍由 `IConfigSystem.GetTable<T>()` 提供，不建立项目 ConfigSystem。

## 对应 GDD 内容

对应 §4.1、§5、§7.1、§7.3、§7.4、§9.1、§12.1、§17.1、§17.5、§20.2。配置表达既定内容，不把 4 槽、6×4、3 阶或初始火球写成 C# 常量。

## 实施范围

### 创建

- `Tools/Luban/DataTables/Datas/法术定义_SpellDefinition.xlsx`：`TbSpellDefinition`，以 `SpellType spellType` 为键，并包含 `bool isOpen`、`int displayPriority`、`string displayNameKey`、`string iconResourceKey`。
- `Tools/Luban/DataTables/Datas/法术阶级_SpellTier.xlsx`：`TbSpellTier`，以 `int tier` 为键，并包含 `bool isHighest`、`string displayNameKey`、`string frameResourceKey`、`float combatFeedbackScale`。
- `Tools/Luban/DataTables/Datas/法术资产规则_SpellAssetRule.xlsx`：`mode=one` 的单条 `TbSpellAssetRule`，字段为 `int id`、`int equipmentSlotCount`、`int craftingRows`、`int craftingColumns`、`SpellType initialSpellType`、`int initialTier`、`int initialLevel`、`int initialEquipmentSlot`。
- `Assets/Game/Scripts/Runtime/Modules/SpellAssets/SpellDomainTypes.cs`：`SpellLocation` 与 `public readonly struct SpellInfo`。

### 修改

- `Tools/Luban/DataTables/Datas/__enums__.xlsx`：新增 `SpellType`（Fireball、ChainLightning、FrostRing、Shield）。
- `Tools/Luban/DataTables/Datas/__tables__.xlsx`：登记上述三张表。
- `Tools/Luban/DataTables/Datas/Language.xlsx`：新增四种法术与三个阶级的中文显示键。

### 不涉及

- 不直接编辑 `Assets/Game/Scripts/Runtime/Generated/Configs/` 或 `Assets/Game/Res/Configs/`；只由现有 `LubanGeneratorWindow.GenerateAll()` 生成。
- 不修改 `Tools/Luban/DataTables/Datas/__beans__.xlsx`；三张表均由各自表头直接定义记录类型。
- 不创建 Store/System/Procedure，不定义战斗数值、升级成本或随机权重。

## 状态与数据

本 MDD 不拥有运行时状态。`SpellInfo` 只携带 `InstanceId`、`SpellType`、`Tier`、`Level`、`SpellLocation`、`EquipmentSlot`、`IsLocked`；它是法术实例的只读业务值，不是可替换 Store Data 的快照。`SpellLocation.CraftingArea = 0`、`SpellLocation.EquipmentSlot = 1`；合成区实例的 `EquipmentSlot` 固定为 `-1`，装备槽按 `0—3` 编号。

## Luban 配置

新增业务 Excel 严格使用“中文业务名_英文标识.xlsx”。表类命名为 `SpellDefinition`、`SpellTier`、`SpellAssetRule`，生成表为 `TbSpellDefinition`、`TbSpellTier`、`TbSpellAssetRule`，顶层模块保持 `cfg`，生成入口保持现有 `LubanGeneratorWindow.GenerateAll()`。

- `SpellType` 使用显式稳定值：`Fireball = 1`、`ChainLightning = 2`、`FrostRing = 3`、`Shield = 4`。
- `TbSpellDefinition` 四行均 `isOpen=true`，`displayPriority` 依次为 10、20、30、40；显示键依次为 `SPELL_FIREBALL_NAME`、`SPELL_CHAIN_LIGHTNING_NAME`、`SPELL_FROST_RING_NAME`、`SPELL_SHIELD_NAME`；资源键依次为 `Spell/Icon/Fireball`、`Spell/Icon/ChainLightning`、`Spell/Icon/FrostRing`、`Spell/Icon/Shield`。
- `TbSpellTier` 三行反馈倍率依次为 1.0、1.25、1.5，只有第三阶 `isHighest=true`；显示键为 `SPELL_TIER_1_NAME`、`SPELL_TIER_2_NAME`、`SPELL_TIER_3_NAME`，资源键为 `Spell/Frame/Tier1`、`Spell/Frame/Tier2`、`Spell/Frame/Tier3`。
- `TbSpellAssetRule` 唯一记录为：`id=1`、`equipmentSlotCount=4`、`craftingRows=6`、`craftingColumns=4`、`initialSpellType=Fireball`、`initialTier=1`、`initialLevel=1`、`initialEquipmentSlot=0`。
- `Language.xlsx` 新增对应中文：火球、雷链、冰环、护盾、一阶、二阶、三阶。资源键只建立代码与后续 Prefab/美术资源的稳定契约，本 MDD 不创建资源。

## 验收标准
