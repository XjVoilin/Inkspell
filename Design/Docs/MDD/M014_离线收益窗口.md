# M014 离线收益窗口

文档类型：MDD

- 来源模块设计：../模块设计.md
- 来源 GDD：../GDD.md

## 目标与边界

确认并复用现有离线收益 Window、WindowData 与 OfflineRewardPresentationSystem。展示适配作为长期 UI 集成能力订阅已完整提交的 OfflineGenerationSettledEvent，在产生数大于零时打开窗口；它不参与收益计算、待领取提交、自动补入或关闭回滚。

## 对应模块设计

- 所属范围：法术生成的 UI 表现集成，不新增业务模块。
- OfflineRewardPresentationSystem 只负责长期订阅已提交事实并打开窗口。
- WindowData 是正常流程和 GM 的唯一显示输入。

## 对应 GDD 内容

对应 §3、§8.3、§15.3、§18 与 §20.11—12。

## 实施范围

### 创建

无。

### 修改

无。M009 保持 OfflineGenerationSettledEvent 与 OfflineGenerationOutcome 外部契约，现有展示连接已经符合目标设计。

### 复用

- Assets/Game/Scripts/Runtime/Modules/UI/OfflineRewardPresentationSystem.cs：现有长期订阅，以及 GeneratedCount > 0 时打开窗口的表现行为。
- Assets/Game/Scripts/Runtime/Views/UIOfflineRewardWindowData.cs、UIOfflineRewardWindow.cs：现有构造、默认 Data 和纯展示行为。
- Assets/Game/Scripts/Runtime/Views/UIWindowID.cs 的 UIOfflineRewardWindow = 14。
- Tools/Luban/DataTables/Datas/UIWindow.xlsx 中同名 ID 14 记录。

### 不涉及

- 不创建弹窗 Prefab、图标、动画或 Inspector 绑定。
- 不在 View 或展示 System 计算收益、修改 Store、重跑结算或阻塞结果成立。

## 前置依赖

无。OfflineGenerationOutcome、OfflineGenerationSettledEvent、UIWindowID 和现有窗口运行基础已经存在；M009 保持这些外部契约。

## 延迟集成

无。OfflineRewardPresentationSystem 的注册、订阅与事件展示连接已经存在且目标保持不变。

## 角色与职责

| 类型 | 所属范围 | JulyArch 角色 | 职责 | 必要协作 |
|---|---|---|---|---|
| OfflineRewardPresentationSystem | UI 表现集成 | System | 长期订阅已提交离线收益事实并打开窗口 | SpellGenerationSystem、IUISystem |
| UIOfflineRewardWindow | UI 表现集成 | Window | 渲染一次已提交结算 | WindowData |
| UIOfflineRewardWindowData | UI 表现集成 | WindowData | 保存正常流程或 GM 注入的显示值 | OfflineGenerationOutcome |

## 状态与数据

PresentationSystem 只缓存 IUISystem 引用，不拥有收益状态。WindowData 只含 ElapsedSeconds、GeneratedCount、TransferredCount；它是显示输入，不是第二份生成权威状态。

## 行为与公开能力

| 类型 | 准确公开签名 | 语义 | 返回与失败处理 |
|---|---|---|---|
| UIOfflineRewardWindowData | public UIOfflineRewardWindowData() | GM/未注入默认 Data | Window 只读取 |
| UIOfflineRewardWindowData | public UIOfflineRewardWindowData(OfflineGenerationOutcome outcome) | 从已提交结果构造显示 | 不触发生成 |
| UIOfflineRewardWindowData | public long ElapsedSeconds { get; set; }、public int GeneratedCount { get; set; }、public int TransferredCount { get; set; } | 唯一显示字段 | 可由 GM 覆盖 |
| OfflineRewardPresentationSystem | protected override UniTask OnInitializeAsync() | 订阅 OfflineGenerationSettledEvent | Framework 关闭时自动退订 |

## View 代码

Window 类型、ID 和 TbUIWindow 保持 UIOfflineRewardWindow/14。OnBeforeOpen() 使用注入 Data，否则创建默认 Data；关闭只结束表现，不修改生成、资产或关卡。

## 验收标准

- 离线收益只在完整提交后展示；GeneratedCount=0 不打开窗口。
- 启动流程不直接承担收益展示判断，窗口关闭不回滚状态。
- Window、ID 与 TbUIWindow 同名同值，并有默认 WindowData。
- 编译通过；不创建测试、Prefab、Scene 或美术资源。
