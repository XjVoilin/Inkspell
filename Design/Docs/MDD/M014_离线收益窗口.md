# M014 离线收益窗口

文档类型：MDD

- 来源模块设计：`../模块设计.md`
- 来源 GDD：`../GDD.md`

## 目标与边界

建立一次离线生成结算的展示 Window 与 WindowData，清楚显示合法离线时长、产生数量和已自动补入数量。它不计算离线收益、不修改待领取或资产、不阻塞业务结果成立。

## 对应模块设计

- 所属范围：法术生成的 View 切片，不新增业务模块。
- 离线收益先由生成模块完整提交待领取并执行可完成的自动补入，再产生真实结果；Window 只播放该结果，打开或关闭均不参与提交。

## 对应 GDD 内容

对应 §3 积累感、§8.3、§15.3 离线反馈、§18 异常时间及 §20.11—12。

## 实施范围

### 创建

- `Assets/Game/Scripts/Runtime/Views/UIOfflineRewardWindow.cs`：继承 `UIView`。
- `Assets/Game/Scripts/Runtime/Views/UIOfflineRewardWindowData.cs`：离线结算唯一显示输入。

### 修改

- `Assets/Game/Scripts/Runtime/Views/UIWindowID.cs`：新增 `public const int UIOfflineRewardWindow = 14`。

- `Tools/Luban/DataTables/Datas/Language.xlsx`：新增离线时长、获得数量、已补入和继续文本键。

### 不涉及

- 不创建弹窗 Prefab、法术图标、动画或 Inspector 绑定。
- 不让关闭动画决定待领取提交或自动补入。

## 延迟集成

## 角色与职责

| 类型 | 所属模块 | JulyArch 角色 | 职责 | 必要协作 |
|---|---|---|---|---|
| `UIOfflineRewardWindow` | 法术生成 View | Window | 渲染一次已提交离线结算 | WindowData |
| `UIOfflineRewardWindowData` | 法术生成 View | WindowData | 保存可由正常流程或 GM 注入的显示值 | `OfflineGenerationOutcome` |

## 状态与数据

WindowData 只含 `ElapsedSeconds`、`GeneratedCount`、`TransferredCount`。这些字段是已完成结算的显示输入，不是第二份生成权威状态。

## 行为与公开能力

| 类型 | 准确公开签名 | 语义 | 返回与失败处理 |
|---|---|---|---|
| `UIWindowID` | `public const int UIOfflineRewardWindow = 14` | 离线收益窗口 ID | 与 Luban 同名同值 |
| `UIOfflineRewardWindowData` | `public UIOfflineRewardWindowData()` | 未注入/GM 默认 Data | 可由 GM 设置显示字段 |
| `UIOfflineRewardWindowData` | `public UIOfflineRewardWindowData(OfflineGenerationOutcome outcome)` | 从真实结算构造显示输入 | 不触发生成或补入 |
| `UIOfflineRewardWindowData` | `public long ElapsedSeconds { get; set; }`、`public int GeneratedCount { get; set; }`、`public int TransferredCount { get; set; }` | 正常流程构造或 GM 覆盖的唯一显示字段 | Window 只读取这些字段 |

## View 代码

`OnBeforeOpen()` 使用注入 Data，否则创建默认 Data；文本使用 `ILocalizationSystem.GetFormat()`；继续/关闭使用 `UISmartButton` 或 `UICloseButton`。正常流程和 GM 均只根据 Data 渲染。

## 验收标准

- Window、ID 常量和 TbUIWindow 同名同值，且具有 WindowData 默认构造。
- 异常/负时长不在 View 修正；View 显示生成模块已给出的合法结果。
- 关闭弹窗不修改生成、资产或关卡业务状态。
- 编译通过，不创建测试、Prefab、Scene 或美术资源。
