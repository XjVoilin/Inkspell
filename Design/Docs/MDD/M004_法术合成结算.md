# M004 法术合成结算

文档类型：MDD

- 来源模块设计：../模块设计.md
- 来源 GDD：../GDD.md

## 目标与边界

把现有 SpellSynthesisProcedure 的同步合法性判定、随机解释、产物选择和资产提交完整收回 SpellSynthesisSystem。一次二合是同步有界业务动作，无等待、跨帧、嵌套或取消价值；模块继续无 Store、无历史、保底、预览或撤销。

## 对应模块设计

- 所属模块：法术合成；一个 System、无 Store、无 Procedure。
- 合成 System 是二合事务唯一编排者；SpellAssetStore 只执行已判定的单 Store 原子提交。
- 普通失败由合成函数记录上下文、发布稳定拒绝事实并返回 false。

## 对应 GDD 内容

对应 §10、§11.1、§14.3 第 5 条、§18、§19.1 第 10—11 项与 §20.3—5。

## 状态与数据

模块无长期状态。输入实例使用 SpellAssetStore 返回的实时 SpellInstance，只在同步调用栈内读取；随机值与选中产物只存在于本次调用。SynthesisRejectReason 和 SynthesisOutcomeKind 保持现有定义。

## 行为与公开能力

| 类型 | 准确公开签名 | 语义 | 返回与失败处理 |
|---|---|---|---|
| SpellSynthesisSystem | public bool TrySynthesize(long firstSpellId, long secondSpellId) | 同步完成一次合法二合或普通拒绝 | 拒绝记录日志、发布拒绝事件并返回 false；提交完成后发布唯一结果并返回 true |
| SpellSynthesisRejectedEvent | public SpellSynthesisRejectedEvent(long firstSpellId, long secondSpellId, SynthesisRejectReason reason) | 构造稳定拒绝事实 | 不携带本地化文本 |
| SpellSynthesisRejectedEvent | public long FirstSpellId { get; }、public long SecondSpellId { get; }、public SynthesisRejectReason Reason { get; } | 向表现提供最小拒绝事实 | 只读 |
| SpellSynthesisResolvedEvent | public SpellSynthesisResolvedEvent(SynthesisOutcomeKind kind, SpellType rewardSpellType, int rewardTier, int inkReward) | 构造已提交结算事实 | 非适用字段保持类型默认值 |
| SpellSynthesisResolvedEvent | public SynthesisOutcomeKind Kind { get; }、public SpellType RewardSpellType { get; }、public int RewardTier { get; }、public int InkReward { get; } | 向表现提供成功产物或失败墨水 | 只读 |

- 六项合法条件由合成 System 唯一判定；非法请求不消耗随机或资产。
- 成功/失败各只有一次 Store 原子提交，提交后才发布结果。
- SpellSynthesisProcedure 已删除，公开入口不再返回 UniTask。
- 项目编译通过；不创建测试、Prefab、Scene 或美术资源。
