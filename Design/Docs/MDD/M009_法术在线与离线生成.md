# M009 法术在线与离线生成

文档类型：MDD

- 来源模块设计：../模块设计.md
- 来源 GDD：../GDD.md

## 目标与边界

保留现有 SpellGenerationStore 与 SpellGenerationSystem，把 OfflineGenerationProcedure 的纯同步计算、待领取提交和自动补入收回 System。在线/离线生成、前后台订阅、关卡间隔解释和待领取移交仍由生成模块唯一编排；不模拟离线战斗。

## 对应模块设计

- 所属模块：法术生成；一个持久 Store、一个 IUpdatableSystem、无 Procedure。
- Store 拥有待领取、周期、生效间隔和离线锚点。
- System 是待领取到 SpellAssetStore 的唯一编排者，并唯一处理设备时间边界。

## 对应 GDD 内容

对应 §4、§8、§14.1—2、§17.3、§18、§19.1 第 13—15 项及 §20.10—12。

## 角色与职责

| 类型 | 所属模块 | JulyArch 角色 | 职责 | 必要协作 |

## 状态与数据

Store Data 保持 Initialized、PendingSpells、CycleProgressSeconds、ActiveIntervalSeconds、InactiveSinceUtcSeconds、HasInactiveAnchor。设备时间是外部边界：负/回拨时长按零收益处理，正时长限制在配置上限；校验只在同步离线结算责任位置执行一次。

## Luban 配置

复用现有两张作者源、表登记和生成 API；最小间隔、离线上限、权重和各关间隔不在 C# 复制或运行时预巡检。

## 验收标准

- 在线与离线都先进入持久待领取，再按容量移交；无产物丢失。
- SettleOffline() 返回时收益已经完整提交，窗口关闭不影响结果。
- OfflineGenerationProcedure 和异步入口已删除；System 直接使用 Store。
- Framework API 与项目编译通过；不创建测试、Prefab、Scene 或资源。
