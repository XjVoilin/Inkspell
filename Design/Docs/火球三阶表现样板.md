# 火球三阶表现样板

用户确认先制作火球的三阶独立图标、施法与命中表现，并在同一场景并排比较。沿用 MainWindow 手绘墨线与羊皮纸美术；以现有 icon_spellFireball.png 为唯一造型参考。此文档更新早期“主图保持相同，仅边框区分阶数”的表现约束。

- 一阶：单颗紧凑火焰，短焰尾，小范围火星。
- 二阶：火核外旋转焰带，宽拖尾，命中时出现环形冲击和更多火星。
- 三阶：炽白核心、外张火焰冠，双焰尾与绕核焰带，命中亮核、分层冲击、向外飞散的火星。
- 轮廓差异在实际卡牌尺寸可识别；按用户最新要求移除卡牌阶数文字、I / II / III 阶标与附加阶级边框；保留基础卡槽底板、等级数字和锁定/选中反馈。
- 施法事实、跨帧攻击和命中事实冻结阶级；视图只播放已提交事实，不改变伤害、范围、冷却、命中时间或目标选择。
- 火球依然是单体伤害，冲击与残留视觉保持在目标附近；效果有对象池上限并在战斗切换/隐藏时清理。
- 图标在 Prefab 中直接引用；运行时切换卡牌、拖动、装备均同步更新；详情页保持现有纯文字布局。
- 三阶并排预览使用同一表现代码和真实生成素材。预览为构造状态，不代表完整实战录屏。

生成方式：内置 image_gen，各阶独立生成透明 PNG；精确提示词见 FireballSample_art_plan.json。源图保存至 Design/AIArt/ArtSource/FireballSample，Unity 素材保存至 Assets/Game/Arts/Textures/FireballSample。
