# 全法术三阶表现

火球三阶样板通过后，将“依靠主图轮廓和战斗动作识别阶级”的规则扩展到连锁闪电、冰环与符文护盾。

- 所有卡牌继续移除阶数文字、阶标和附加阶级边框；保留基础卡槽底板、等级、锁定、选中和冷却。
- 连锁闪电：一阶单束折线；二阶三叉闪电；三阶雷核向外伸出多条分支。战斗中阶级越高，主雷线越粗、分支越多。
- 冰环：一阶稀疏单层六晶环；二阶双层八晶环；三阶密集雪花冰冠。战斗中阶级越高，展开范围越大、旋转层次越强。
- 符文护盾：一阶紧凑基础盾；二阶宽体加固盾；三阶展翼符文重盾。战斗中阶级越高，护罩面积与脉冲幅度越大。
- 阶级随 BattleAttack / BattleFact 冻结；换装不会改变已经发出的法术表现。
- 不修改伤害、护盾值、冷却、命中时间、效果范围或目标选择。
- 每张生产图独立生成透明 PNG；不得带文字、卡框、纸张背景或棋盘格。

素材来源为现有三张法术图标，仅作为配色、墨线与媒介参考。精确提示词记录在 SpellTierPresentation_art_plan.json。
