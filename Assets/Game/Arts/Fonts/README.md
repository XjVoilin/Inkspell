Inkspell UI uses LXGW WenKai Regular (霞鹜文楷), version 1.522:
https://github.com/lxgw/LxgwWenKai/releases/tag/v1.522

The original font is distributed under the SIL Open Font License 1.1 (OFL.txt).
LXGW WenKai SDF is generated by InkspellUIPrefabGenerator from this font and
prewarmed with printable ASCII and the current localization table. Dynamic glyph
population remains enabled for later text changes. Legacy UI Text uses the same
TTF source, so Chinese text, headings, and numbers share one typeface.

Use July > Inkspell > Apply Project UI Font to update existing game prefabs and
the TMP default font. Newly generated interface text also uses this typeface.
